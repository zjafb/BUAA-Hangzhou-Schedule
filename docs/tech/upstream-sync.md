# 杭州版 v1.0.5 上游同步与验证

同步来源：BUAASubnet/UBAA `upstream/main`，提交 `155e8b56`（v1.8.2），前次基线 `1f4b8f84`（v1.8.0）。

## 合入范围

- CAS 旧 HTTP 跳转升级为 HTTPS，保留 service 参数的原始编码；直连与 WebVPN 分别跟随正确的认证地址。
- WebVPN 地址转换保留尾斜杠和片段查询参数，避免登录循环。
- 移除失效的服务器中转入口，迁移旧设置时同步认证表单。
- 希冀 HTTPS 服务登录、登录页识别、WebVPN 课程切换串行化，避免跨课程会话串用；重置会话同时清除数据缓存。
- 新增 iHome 客户端接口、页面和高级功能入口；HTML 文本转换独立实现，不恢复杭州版已移除的 SPOC 模块。

本仓库仅构建客户端，不引入上游服务端、iOS 发布流程及已裁剪的北京校区功能。

## 提醒修复

课程时刻按 Asia/Shanghai 解析。PendingIntent 使用课程日期、名称、地点、时段构成稳定身份；重排只移除失效课程，保留已到点未投递提醒。持久记录已投递课程，拒绝提前、失效身份及旧提前分钟数的广播。设置保存、时钟变化、时区变化、重启、升级和精确闹钟授权时重排。

课程及计划使用 AlarmManager.setAlarmClock，系统可显示下一次闹钟；缺少精确闹钟权限时仍退回非精确提醒，界面保留权限提示。系统强行停止、禁用通知及部分厂商后台限制仍会影响通知展示。
